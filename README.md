# Сайт NIKA CAKES — Вероника Бовшис, кондитер, Минск

Одностраничный сайт-макет. Это обычные файлы без базы данных и без сборки:
открывается в любом браузере и бесплатно размещается на GitHub Pages.

Сейчас это **визуал для обсуждения с заказчиком**: форма заявки ничего не отправляет,
часть текстов и цифр — черновик.

## Фотографии

Лежат в `assets/img/photos/`. У каждого фото два файла:

- `имя-sm.webp` — для телефона (800 px по ширине);
- `имя-lg.webp` — для компьютера и полноэкранного просмотра (до 1600 px).

Чтобы заменить фото, положите новые файлы **с теми же именами**, код править не нужно.

| Имя | Где на сайте |
|---|---|
| `hero-mobile` | первый экран на телефоне (вертикальное фото) |
| `hero-desktop` | первый экран на компьютере (горизонтальное фото) |
| `about-1`, `about-2` | «Привет, я Вероника» |
| `cat-macaron`, `cat-cakes`, `cat-truffles`, `cat-zefir` | плитки «Что я готовлю» |
| `signature-truffles` | «Трюфели с сыром с голубой плесенью» |
| `cake-1` … `cake-8` | лента «Торты на заказ» |
| `holiday-feb14`, `holiday-mar8`, `holiday-easter`, `holiday-sep1`, `holiday-mothers`, `holiday-newyear`, `holiday-birthday` | «Сладкий повод есть всегда» |
| `gallery-01` … `gallery-12` | галерея «Из Instagram» |

Логотипы — в `assets/img/`: кремовый для тёмного фона, коричневый для светлого,
на заставке — кремовый `logo-cream.png`, свечение за пламенем рисуется стилями.
`logo-glow.jpg` (размытое свечение из исходника) больше не используется.

## Цвета и шрифты

Все цвета — в начале файла `assets/css/styles.css`, блок `:root`.
Например, `--caramel` — цвет кнопок, `--choc-500` — шоколадные блоки, `--cream` — фон.

Шрифты: Cormorant Garamond (заголовки), Manrope (текст), Marck Script (подпись «Вероника»).

## Как посмотреть у себя

Откройте `index.html` двойным щелчком. Если карта или шрифты не загрузились,
запустите локальный сервер в этой папке:

```bash
python -m http.server 8124
```

и откройте `http://localhost:8124`.

## Как выложить на GitHub Pages

Git устанавливать не нужно — всё делается на сайте github.com.

1. Войдите на github.com → кнопка **New** (новый репозиторий).
   Название, например, `nika-cakes`. Отметьте **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**
   (или **Add file → Upload files**).
3. Перетащите в окно **содержимое** папки `nika-cakes`: файлы `index.html`, `README.md`,
   `.nojekyll` и папку `assets` целиком. Нажмите **Commit changes**.
   > Файл `.nojekyll` скрытый. Если Windows его не показывает: в Проводнике
   > «Вид → Показать → Скрытые элементы».
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/nika-cakes/`.
   Эту ссылку можно отправить заказчику, она открывается и с телефона.

Чтобы обновить сайт, снова загрузите изменённые файлы через **Add file → Upload files**,
файлы с теми же именами заменятся.

```

├── index.html            вся страница: тексты, разделы, форма
├── .nojekyll             нужен GitHub Pages, не удалять
└── assets/
    ├── css/styles.css    оформление (цвета — в самом начале)

        └── photos/       фотографии из Instagram
```

## Что уже учтено для телефона

- Первый экран всегда целиком помещается в экран, адресная строка его не обрезает.
- Снизу появляется панель «Позвонить · Direct · Заказать», когда кнопки первого экрана уходят вверх.
- Все кнопки не меньше 44 px — удобно попадать пальцем.
- Ленты тортов и праздников листаются пальцем, фото в галерее открываются на весь экран
  и закрываются свайпом вниз.
- В форме телефон открывает цифровую клавиатуру, дата — календарь; раньше завтрашнего дня выбрать нельзя.
- Фото сжаты в WebP и грузятся только при прокрутке к ним.
- Если в телефоне включено «Уменьшить движение», анимации отключаются.
